# Day 08 Quiz
## 1. What is the difference between .remove() and .pop()?
Answer: .remove() removes an item by its value while .pop() removes an item by its index.

## 2. Does .sort() return a new list or sort in place?
Answer: .sort() sorts the existing list in place. It does not create and return a new sorted list.

## 3. What does my_list[::2] do?
Answer: It uses slicing to take every second element of the list starting from the beginning.
